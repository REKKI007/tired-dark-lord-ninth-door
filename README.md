A 100-word villain monologue for the make.fun bounty
[The Tired Dark Lord: A 100-Word Villain Monologue](https://make.fun/competitions/u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb).

Pell, warden of the ninth door, has held its key through four kings — five? —
and polished the floor for a hundred heroes. The door opens only from inside.
One of us walks out, and the other stays.

Run `python3 main.py` and it writes the monologue (99 words, 499 characters)
to `/output/entry.txt`.
